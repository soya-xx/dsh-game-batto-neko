# BattoNeko (拔刀猫耳) · DSH Game Store package

A pixel-art action platformer. This repository holds the game package published to the
[DSH Game Store](https://dsh-game-store.com): `game/` is the playable build, `store/` holds the store page art and text.

**About the source:** the game is developed in a private repository. `game/game.js` is a build of it with comments removed
and internal names shortened; it is the complete game logic, but the original source is not published here.
The store version is limited to the opening chapters (through Hamster Town); later chapters are still in development.
